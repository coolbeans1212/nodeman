# NODEMAN
PHP Utility for managing node.js projects on GNU/Linux systems, using the 7.css library (or 98.css, or xp.css: you can customise) for styling. It can handle multiple projects at once, with multiple different versions for each project. It can also manage Node.js dependencies with NPM.
## Requirements
- GNU/Linux Debian or similar.
- PHP >=8.4.
- MariaDB or MySQL.
- A web server (such as Apache).
- Node.js.
